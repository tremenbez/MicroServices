Задание №4: Разработка Auth-сервиса на Python

Создать Auth-сервис, обеспечивающий аутентификацию и авторизацию пользователей с использованием JWT-токенов. Реализовать функционал хранения данных в базе и обработку запросов с учетом безопасного управления токенами. 
Требуемые эндпоинты:

1.	Регистрация пользователя
o	Метод: POST
o	Эндпоинт: /register
o	Описание: Создание нового пользователя в системе, если email еще не зарегистрирован.
Данные запроса: 
{
  "email": "example@example.com",
  "password": "securepassword"
}

2.	Аутентификация пользователя
o	Метод: POST
o	Эндпоинт: /login
o	Описание: Вход в систему по email и паролю, возвращает access и refresh токены.
Данные запроса: 
{
  "email": "example@example.com",
  "password": "securepassword"
}

3.	Обновление токенов
o	Метод: POST
o	Эндпоинт: /refresh
o	Описание: Обновление access токена с использованием refresh токена.
Данные запроса: 
{
  "refresh_token": "your_refresh_token"
}

4.	Изменение данных пользователя
o	Метод: PUT
o	Эндпоинт: /user/update
o	Описание: Обновление email или пароля авторизованного пользователя.
Данные запроса: 
{
  "email": "newemail@example.com",
  "password": "newpassword"
}

5.	Просмотр истории входов
o	Метод: GET
o	Эндпоинт: /user/history
o	Описание: Возвращает историю входов в аккаунт для авторизованного пользователя.

6.	Выход из системы
o	Метод: POST
o	Эндпоинт: /logout
o	Описание: Удаляет токен пользователя из списка действительных.
